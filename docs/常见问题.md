# 常见问题

**Q：面板里改了配置没反应？**
确认文件名是 `data/config/<插件目录名>_config.json`（如 `smart_reply_config.json`），不是 `astrbot_plugin_xxx_config.json`。

**Q：她几乎不接话？**
1. `name_keywords` 是否填了机器人名字
2. `judge_threshold` 是否过高（先降到 50）
3. 看 `data/plugin_data/smart_reply/decisions.jsonl` 里的分数分布

**Q：她太吵、老插话？**
`judge_threshold` 提到 70，`recent_reply_bonus` 提到 25。

**Q：B 站视频她不看？**
群里必须 @ 她（或把 `require_at_in_group` 设为 false），且消息里要有 `BV号` / `b23.tv` 链接。

**Q：转发消息还是空的？**
确认 `forward_reader` 已启用。QQ 部分卡片只给预览行，拿不到全文属协议限制。

**Q：唱歌跑调？**
MiMo 的唱歌是「唱腔朗读」，没有旋律输入，不保证对上原曲音高。歌词短一点、音程跳跃少一点会更稳。

**Q：语音偶尔没有？**
语音由 AstrBot 自带 TTS 负责，撞到服务商限流会自动退回纯文字，与本套件无关。

**Q：戳一戳失败 `OIDB error 1002`？**
对方不允许被戳或被服务端限流，不是插件故障。
