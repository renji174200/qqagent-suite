# 配置说明

所有配置都在 AstrBot 面板 →「插件」→ 对应插件卡片里修改，保存后生效。

## smart_reply · 接话

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关 |
| `judge_provider_id` | 空 | 判断模型，留空用当前对话模型 |
| `judge_fallback_provider_id` | 空 | 主模型限流时的备用模型 |
| `judge_threshold` | 60 | 分数线，越高越安静 |
| `recent_reply_bonus` | 15 | 刚回复后临时提高的门槛 |
| `recent_reply_window_sec` | 300 | 「刚回复」判定窗口 |
| `context_size` | 30 | 判断时参考的历史条数 |
| `min_text_len` | 3 | 最短处理长度 |
| `cooldown_sec` | 0 | 接话冷却 |
| `max_judge_per_minute` | 0 | 每分钟判断上限，0 = 不限 |
| `quiet_hours` | 空 | 免打扰，如 `1-8` |
| `name_keywords` | 空 | **必填**：机器人名字/外号 |
| `force_keywords` | 空 | 催促词，命中直接接话 |
| `signal_keywords` / `require_signal` | 见面板 | 指向性词粗筛 |
| `ignore_senders` | 空 | 忽略的发送者昵称 |
| `skip_commands` | false | 跳过 `/` 开头指令 |
| `enable_continuation` | false | 「接上一句」规则 |
| `decision_log` | true | 写判断日志 |
| `judge_prompt` | 空 | 自定义提示词，留空用内置 |

### 调优

| 现象 | 调整 |
|---|---|
| 太吵 | `judge_threshold` 70、`recent_reply_bonus` 25 |
| 太静 | `judge_threshold` 50，确认 `name_keywords` 正确 |
| 刚回又接 | `recent_reply_window_sec` 600 |
| 判断慢 | `context_size` 20，或换轻量模型 |

判断日志：`data/plugin_data/smart_reply/decisions.jsonl`

## bili_watch · B站

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关 |
| `provider_id` | 空 | 视觉模型，留空用当前模型 |
| `sessdata` | 空 | B站登录态（部分视频需要） |
| `frames` | 12 | 抽帧数量 |
| `frame_width` | 960 | 单帧宽度（px） |
| `max_duration_sec` | 900 | 视频时长上限 |
| `max_download_mb` | 45 | 下载体积上限 |
| `require_at_in_group` | true | 群里必须 @ |
| `cooldown_sec` | 60 | 同视频冷却 |
| `note_ttl_minutes` | 120 | 笔记有效期 |

触发：群里 @ 她 + 消息含 `BV号` 或 `b23.tv` 链接。

## forward_reader · 看转发增强

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关 |
| `max_depth` | 3 | 嵌套转发深度 |
| `max_nodes` | 60 | 最多展开条数 |
| `max_chars` | 4000 | 注入文本上限 |

## poke_tool · 戳

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` / `tool_enable` | true | 开关 |
| `auto_enable` | false | 自动戳（非模型触发） |
| `auto_sessions` | [] | 自动戳生效会话 |
| `idle_minutes` | 20 | 空闲判定 |
| `interval_min_minutes` / `interval_max_minutes` | 30 / 80 | 自动戳间隔 |
| `quiet_hours` | 空 | 免打扰 |
| `max_per_day` | 8 | 每人每天上限 |
| `cooldown_sec` | 90 | 冷却 |
| `provider_id` | 空 | 使用的模型 |

## reply_target · 引用

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关 |
| `auto_quote_group` | true | 群里自动引用 |
| `auto_quote_private` | false | 私聊自动引用 |
| `auto_quote_probability` | 0.4 | 自动引用概率 |
| `at_in_private` | false | 私聊用 @ 指向 |
| `cooldown` | 0 | 冷却（秒） |

## mimo_sing · 唱歌

| 配置 | 默认 | 说明 |
|---|---|---|
| `api_key` | 空 | **必填**：MiMo API Key |
| `model` | mimo-v2.5-tts | 模型 |
| `voice` | 冰糖 | 音色（克隆音色不支持唱歌） |
| `style` | 唱歌 | 风格标签 |
| `user_prompt` | Hello, MiMo… | 演唱提示词 |
