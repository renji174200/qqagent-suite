# 全智能QQagent · 看转发增强（forward_reader）

解决三个「她看不懂」的问题：转发消息、嵌套转发、QQ 卡片。

## 优势

- **嵌套转发递归展开**：转发里套转发也能读到最内层
- **卡片解析**：QQ 小程序、网易云音乐、公众号文章 → 标题 + 描述 + 链接
- **引用里的卡片也能读**：主动拉取被引用的原消息再解析
- **纯文本处理**：不调用模型，零 token 成本

## 能力对照

| 输入 | 处理结果 |
|---|---|
| 普通转发 | 逐条「昵称：内容」 |
| 嵌套转发 | 递归展开（最多 N 层） |
| 小程序卡片 | `[卡片] 标题 \| 描述 \| 链接` |
| 引用卡片 | 拉原消息后再解析 |

## 配置

| 配置 | 默认 |
|---|---|
| `max_depth` | 3 |
| `max_nodes` | 60 |
| `max_chars` | 4000 |

## 限制

QQ 只给预览行的卡片（XML 形式）拿不到全文，只能读预览；这是协议层限制。
