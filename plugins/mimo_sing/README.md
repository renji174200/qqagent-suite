# 唱歌（mimo_sing）

用 MiMo TTS 的唱歌模式演唱歌词，发成语音。

## 优势

- **两种触发**：`/唱歌 歌词` 或让模型调用 `sing_song`
- **自动断句**：逗号分号转成换行，给模型换气位置
- **参数可调**：音色、风格标签、提示词都能改

## 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `api_key` | 空 | **必填**，MiMo API Key |
| `model` | mimo-v2.5-tts | 预置音色模型 |
| `voice` | 冰糖 | 音色（克隆音色不支持唱歌） |
| `style` | 唱歌 | 风格标签 |
| `user_prompt` | Hello, MiMo… | 演唱提示词 |

## 说明

MiMo 的唱歌是「唱腔朗读」，没有旋律输入，**不保证对上原曲音高**。
想要更稳，歌词短一点、音程跳跃少一点。
