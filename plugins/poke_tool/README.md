# 全智能QQagent · 戳（poke_tool）

让模型自己决定什么时候戳人，而不是定时骚扰。

## 优势

- **模型驱动**：提供 `poke_user` 工具，由她判断语境（被调侃、被叫外号、对方主动要求）
- **安全阀**：每人每天上限 + 冷却，防止刷屏
- **可完全关闭自动戳**：默认只在她想戳时戳

## 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `tool_enable` | true | 允许模型调用 |
| `auto_enable` | false | 非模型触发的自动戳 |
| `max_per_day` | 8 | 每人每天上限 |
| `cooldown_sec` | 90 | 冷却 |
| `quiet_hours` | 空 | 免打扰，如 `1-8` |

## 注意

QQ 返回 `OIDB error 1002` 表示对方不允许被戳或被限流，是服务端拒绝，不是插件故障。
