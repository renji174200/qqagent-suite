# 全智能QQagent · B站（bili_watch）

发一个 B 站链接，她会真的“看”视频画面，然后跟你聊内容。

## 优势

- **抽帧不抽风**：均匀取 N 帧（默认 12）、每帧 960px，快速剪辑也不漏关键画面
- **三层信息**：画面 + 标题简介 + 字幕（有的话），理解更准
- **会记内容**：笔记缓存 120 分钟，两小时内都能追问
- **成本可控**：帧数、宽度、时长、体积全部可调

## 触发条件

1. 群里必须 **@ 她**（可关）
2. 文本里有 `BV号` 或 `b23.tv` 短链接
3. 同一视频 60 秒内只处理一次

## 配置要点

| 配置 | 默认 | 说明 |
|---|---|---|
| `frames` | 12 | 抽帧数 |
| `frame_width` | 960 | 单帧宽度 |
| `max_duration_sec` | 900 | 视频时长上限 |
| `max_download_mb` | 45 | 下载体积上限 |
| `sessdata` | 空 | 可选，部分视频需要 |
| `provider_id` | 空 | **下拉选择**视觉模型（需支持图片）；留空用当前模型 |

## 成本

12 帧 × 960px ≈ 8000~11000 token / 视频。帧数和宽度减半，成本大致减半。
